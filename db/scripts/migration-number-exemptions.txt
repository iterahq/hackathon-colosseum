# db/scripts/migration-number-exemptions.txt
#
# Migration filenames allowed to share a 4-digit number with another file.
# Read by db/scripts/check-migration-numbers.sh. One filename per line;
# `#` starts a comment. A number is only forgiven when EVERY file claiming it is
# listed here — so adding a third file to an exempted number still fails.
#
# THIS LIST IS NOT A CONVENIENCE. Every entry is a collision that could not be
# undone, because undoing it means RENAMING A MIGRATION THAT IS ALREADY APPLIED,
# and itera.schema_migrations is keyed by filename: the renamed file has no
# ledger row, `classify()` calls it PENDING, and the next `db-apply` re-runs it
# against the ITERA production database. For a file containing a DROP or a
# non-fixpoint backfill that is an outage, not an inconvenience.
#
# If your new migration collides, RENUMBER YOUR OWN FILE — it is not applied yet,
# so renaming it costs nothing. Do not add it here.
